# Что почистить в Claude Code после того, как вас забанили

Если при входе в Claude появился экран блокировки, чистить компьютер для подачи апелляции не требуется. Сначала откройте этот аккаунт в браузере: на экране ограничения Anthropic показывает доступные действия, включая форму апелляции и, в предусмотренных случаях, экспорт данных. Это стоит сделать до того, как разбирать файлы на диске. [Инструкция Anthropic](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals).

Если задача — закончить работу на этом компьютере, для входа через аккаунт у Claude Code есть штатная команда `/logout` внутри CLI. Если в проекте использовался отдельный API-ключ и он попал в чужие руки, его следует отозвать у провайдера: удаление локальной копии оставляет уже скопированный секрет действительным. [Как Claude Code хранит учётные данные](https://code.claude.com/docs/en/authentication#credential-management).

Если нужно освободить место или подготовить компьютер к использованию другого аккаунта, скрипты ниже удаляют конфигурацию и учётные данные Claude Code.

## Что хранится в профиле

**Основной файл — `~/.claude.json`:**

- **userID** — создаётся случайно при первом запуске: 32 байта, записанные как 64 шестнадцатеричных символа. Сохраняется в конфиге независимо от аккаунта.
- **machineID** — другой случайный идентификатор такого же формата. Сохраняется в этом же конфиге. Код отчётов об ошибках использует его 12-символьный префикс. Это не аппаратный серийный номер и не `/etc/machine-id`.
- **oauthAccount** — сведения об аккаунте: UUID аккаунта и организации, email, параметры подписки. Эти данные приходят от сервера при авторизации.

**Другие файлы:**

| Файл | Что в нём |
| --- | --- |
| `~/.claude/.credentials.json` | Токены доступа и обновления, сроки действия и разрешения. Их выдаёт сервер авторизации; они привязаны к аккаунту. |
| `~/.claude/.claude.json` | Возможный альтернативный конфиг при другом каталоге конфигурации. Может содержать отдельную пару userID / machineID. |
| `~/.claude/.config.json` | Альтернативное расположение глобального конфига, поддерживаемое кодом клиента. Проверять, только если файл существует. |
| `~/.claude/backups/.claude.json.backup.*` | Резервные копии конфига, которые могут сохранять прежние ID. |

**anonymousId** вида `claudeco…` — в проверенной версии и конфиге не обнаружен.

## Перед использованием другого аккаунта

1. Закрыть все процессы Claude Code.
2. Удалить `~/.claude.json` и `~/.claude/.credentials.json`.
3. Если существуют — удалить альтернативные конфиги (`~/.claude/.claude.json`, `~/.claude/.config.json`).
4. Чтобы не оставлять локальные копии прежних ID, удалить соответствующие резервные копии из `~/.claude/backups/`.
5. Убрать старые ключи и токены из переменных окружения и `settings.json`.
6. Запустить Claude заново и авторизоваться только в новом аккаунте. Старый конфиг не восстанавливать.

## Скрипты очистки

Скрипты закрывают процессы Claude Code и удаляют файлы конфигурации и учётные данные. Перед запуском сохраните важные данные, если они есть.

### Linux и macOS

```bash
curl -fsSL https://raw.githubusercontent.com/stufently/claude-code-config-audit/main/cleanup.sh | bash
```

Или скачайте и запустите локально:

```bash
git clone https://github.com/stufently/claude-code-config-audit.git "$HOME/claude-code-config-audit"
bash "$HOME/claude-code-config-audit/cleanup.sh"
```

### Windows (PowerShell)

```powershell
irm https://raw.githubusercontent.com/stufently/claude-code-config-audit/main/cleanup.ps1 | iex
```

Или скачайте и запустите локально:

```powershell
git clone https://github.com/stufently/claude-code-config-audit.git "$HOME\claude-code-config-audit"
& "$HOME\claude-code-config-audit\cleanup.ps1"
```

## Что делают скрипты

1. Завершают все процессы `claude` и `node`, связанные с Claude Code.
2. Удаляют `~/.claude.json` (содержит userID, machineID, oauthAccount).
3. Удаляют `~/.claude/.credentials.json` (токены доступа).
4. Удаляют `~/.claude/.claude.json` и `~/.claude/.config.json`, если они существуют.
5. Удаляют резервные копии из `~/.claude/backups/.claude.json.backup.*`.
6. Выводят список удалённых файлов.

После запуска скрипта откройте новый терминал, чтобы сбросить переменные окружения, и запустите Claude Code заново для авторизации в новом аккаунте.

## Что скрипты не делают

- Не изменяют `settings.json` — если в нём были API-ключи или токены, удалите их вручную.
- Не очищают переменные окружения в текущей сессии — откройте новый терминал.
- Не удаляют проектные настройки из `.claude/` в каталогах проектов.
- Не гарантируют полную анонимизацию — для этого нужны дополнительные меры за пределами этих скриптов.

## Проверка передачи идентификаторов

Передачу userID и machineID с каждым запросом модели я не проверял напрямую. Чтобы утверждать, что определённая версия CLI передаёт локальное поле с каждым запросом, нужно отдельное наблюдение сетевого обмена. Здесь такого измерения не было.

Если ошибка относится к приостановке аккаунта, её рассматривает поддержка через форму апелляции. [Порядок апелляции](https://support.claude.com/en/articles/8241253-safeguards-warnings-and-appeals).
