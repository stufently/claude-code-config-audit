# Инструменты для локального профиля Claude Code

Bash-утилита для проверки прав файла входа и расположения настроек Claude Code в Linux.

## Проверить права в Linux

Откройте терминал в каталоге **проекта, который хотите проверить**. Первый раз скачайте утилиты в домашний каталог и запустите аудит, оставаясь в проекте:

```bash
git clone https://github.com/stufently/claude-code-config-audit.git "$HOME/claude-code-config-audit"
bash "$HOME/claude-code-config-audit/audit.sh"
```

При следующем запуске нужна только вторая команда. Требуются Bash и stat с поддержкой `-c %a`. Скрипт проверяет пользовательские настройки и файл входа из каталога конфигурации, а также настройки текущего проекта. Вывод содержит фиксированные названия и права. Пример для тестового профиля:

```text
user-settings: present, mode 644
credentials: present, mode 644 (expected 600)
project-settings: not found
project-local-settings: not found
```

Для файла входа Anthropic указывает режим 600. При 644 биты группы и остальных пользователей разрешают чтение. При 400 файл доступен владельцу только для чтения: скрипт также отметит отличие от 600. Для оценки фактического доступа нужны ещё владелец, права каталогов и ACL. [Документация по хранению учётных данных](https://code.claude.com/docs/en/authentication#credential-management).

Код выхода 0 означает, что проверка завершена без замечаний; необязательные отсутствующие файлы допустимы. Код 1 означает отличие режима, недоступный каталог, неожиданный тип файла или пропущенную символьную ссылку вместо файла. Код 2 — ошибка вызова или платформы.
